# JSON-снимки всех публичных методов MAX PHP SDK

Свежий набор от **2026-11-10**, SDK **0.4.0 local candidate**.
Содержит 528 JSON-файлов методов с учётом наследования: 357 собственных публичных
методов/деклараций, включая 9 стандартных enum helpers, и 171 унаследованный метод.
353 собственных метода с телом фактически выполнены. Четыре интерфейсные декларации
привязаны к выполненным реализациям. Абстрактный получатель также помечен явно:
невозможно создавать экземпляр abstract class ради фиктивного снимка.

- [index.json](index.json): полный машиночитаемый индекс и результаты покрытия.
- [methods-index.md](methods-index.md): ссылки на все файлы по методам.
- `methods/`: реальные аргументы/результаты/исключения и состояние объектов SDK
  в обезличенном типизированном представлении.
- `responses/`: 111 свежих HTTP-тел через Guzzle и Joomla HTTP и их redaction maps.
- [source-hashes.json](source-hashes.json): точная ревизия всех исходных PHP-файлов.
- [verification.json](verification.json): результаты независимой проверки набора.

В каждом файле метода указаны parameters, return_type, фактические snapshots,
provenance, outcome и redactions. Origin `synthetic_local_fixture_execution`
означает реальное выполнение SDK на явно тестовых данных; это не ответ MAX.
Origin `fresh_max_api_execution` относится к свежему API-прогону. Вложенные
Entity/DTO отражают фактически возвращённое SDK значение. Объекты внешних зависимостей
представлены классом, полные HTTP-тела вынесены отдельно. Хэш execution record
позволяет мейнтейнеру сверить первичное evidence без публикации приватных записей.

Секреты, токены, значения заголовков/настроек, IDs, время, имена, произвольные
тексты, URL, пути машины и бинарные значения замаскированы как **XXXX**.
Динамические ключи заменены уникальными XXXX_N с сохранением числа записей.
Безопасные booleans/null, типы, классы и структурные enum остаются видимыми.
В redaction map записан исходный JSON-тип каждого замаскированного значения.
Число, скрытое строкой XXXX, нельзя передавать в SDK как настоящий ID/параметр;
API-схемы проверяются на оригиналах, а не на этом обезличенном представлении.

Оба HTTP-клиента выполнили по 54 live-сценария. Все 40 операций API вызваны;
31 имеют положительные наблюдения. Для chats.list/getByLink, delete/leave,
изменения участников/прав и messages.answerCallback сохранены контролируемые
отрицательные либо legacy outcomes. Они не названы успешными сценариями.
Реальные чаты не удалялись, права реальных участников не менялись ради проверки.
Созданные тестовые сообщения/комментарии удалены; команды, подписки, закрепление
и настройки чата сопоставлены с исходным состоянием. Неиспользованные резервные
upload tokens не имеют отдельного API удаления и остаются на стороне провайдера.

В тестовых клиентах по ранее выданному разрешению проверка сертификата была
отключена после ошибки проверки цепочки доверия; defaults библиотеки сохранены.
Локальная suite прошла: 157 tests / 428 assertions. Инструментированная отдельная
копия SDK прошла те же проверки, а восстановленные AST всех 87 файлов совпали с
оригиналами. Продуктовые исходники не редактировались.

Покрыты все публичные методы, а не все комбинации аргументов или ветви выполнения.
Внутри файла оставлено до двух различных обезличенных результатов на phase/outcome;
оба live-транспорта сохраняются. Первичные записи остаются приватными.
