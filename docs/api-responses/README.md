# Обезличенные ответы MAX API

Этот каталог содержит реальные JSON-тела ответов MAX Platform API, полученные во время live-тестов SDK и очищенные для публикации.

Правила публикации:

- API-токены, Authorization-заголовки и тела запросов не публикуются;
- идентификаторы, timestamps, имена, usernames, тексты и ссылки заменяются на `XXXX`;
- структура объектов, названия полей, типы безопасных значений и фактические HTTP outcomes сохраняются;
- приватные исходные снимки остаются только в игнорируемом внутреннем каталоге;
- каждый набор содержит `index.json` с происхождением, транспортом и сценарием снимка.
- набор 2026-11-10 опубликован с окончаниями строк LF; его индексные `sha256`
  проверяют файлы публикации, а хэши исходников и первичных записей сохраняют
  историческое происхождение прогона.

## Наборы

- [2026-11-10](./2026-11-10/index.json): 528 файлов публичных методов с учётом
  наследования и 111 свежих HTTP-тел через Guzzle и Joomla HTTP. Локальные fixtures
  и реальные ответы MAX явно различаются. Все 353 собственных метода с телом
  выполнены; четыре интерфейсные декларации связаны с выполненными реализациями.
  [Список методов](./2026-11-10/methods-index.md) содержит ссылки на каждый JSON.
  Исходные типы замаскированных значений указаны в redaction maps; оригиналы
  HTTP-ответов проверены по API-схемам. XXXX не является значением для SDK.
- [Схемы 2026-11-02](../api-schemas/2026-11-02/index.json): исторический набор
  40 схем по 124 наблюдениям. Тела того прогона остаются приватными; свежий набор
  выше опубликован отдельно с точным происхождением. PHPDoc после записи снимков
  уточнён без изменения исполняемых tokens; source-hashes внутри снимка относятся
  к фактически проверенной ревизии до этих текстовых изменений.
- [Comment CRUD, 2026-08-31](./2026-08-31/comment-crud/index.json) — успешные ответы пяти comment endpoints через Guzzle и Joomla HTTP, включая проверки до редактирования, после редактирования и после удаления.
