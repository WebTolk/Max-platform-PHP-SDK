# MAX API JSON Schemas

This directory contains anonymized method-level JSON schemas generated from local live API dumps.

The published schema pack intentionally excludes local raw-dump file references.

Sensitive IDs, usernames, bot/user names, URLs, tokens and message-like values are replaced with `XXXX`.
